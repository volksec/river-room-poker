# River Room Poker

Acesse e jogue: **https://volksec.github.io/river-room-poker/**

Uma sala demonstrativa de Texas Hold’em, feita para partidas locais no navegador. Abra o link, escolha uma mesa e jogue com fichas fictícias.

## O que há nesta versão

- Lobby responsivo com mesas e torneios de demonstração.
- Mesa jogável com distribuição de cartas, blinds, passar, pagar, aumentar, desistir e showdown.
- Melhor combinação de poker calculada entre as sete cartas disponíveis.
- Apelido e estatísticas de demonstração salvos apenas no armazenamento local do navegador.

## Limites

Esta versão não oferece multiplayer em rede, contas, depósitos, saques ou prêmios em dinheiro. Os outros jogadores, torneios e classificação são simulações locais. Não existe servidor de jogo nem transmissão de dados pessoais.

## Publicação

Site estático publicado pelo GitHub Pages. As alterações enviadas à branch `main` são implantadas automaticamente pelo GitHub Actions.
